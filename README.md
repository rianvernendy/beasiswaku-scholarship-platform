# BeasiswaKu

BeasiswaKu is a platform designed to assist students in Indonesia in finding and applying for scholarships. The application features popular scholarships, upcoming webinars, a comprehensive search tool, and valuable resources for students aiming to further their education.

## Project Overview

BeasiswaKu provides a user-friendly interface where students can search for scholarships based on various criteria, including education level, field of study, and eligibility requirements. Additionally, the platform includes webinars that offer tips and insights into applying for scholarships successfully.

## Installation

To set up the project locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone <repository-url>
   ```

2. **Navigate into the project directory:**

   ```bash
   cd beasiswaku
   ```

3. **Open the `index.html` file in your preferred web browser to view the application.** No server configuration is needed as the project consists of static HTML files.

## Usage

- **Home Page:** The landing page features an introduction, a search functionality for scholarships, and calls to action for upcoming webinars.
- **Scholarship Search:** Users can input their preferences through a search form to find relevant scholarships.
- **Webinar Registration:** Users can register for various webinars designed to enhance their scholarship application skills.
- **Testimonials:** The site displays success stories from previous scholarship recipients to inspire and guide current users.

## Features

- Comprehensive search for various scholarships.
- Upcoming webinars to assist with scholarship applications.
- User testimonials showcasing successful scholarship recipients.
- Well-structured and responsive design thanks to Tailwind CSS.
- Mobile-friendly navigation.

## Dependencies

This project uses the following dependencies:

- [Font Awesome](https://fontawesome.com/) - for icons

## Project Structure

The project structure is as follows:

```
beasiswaku/
├── index.html                  # Main landing page
├── cari-beasiswa.html          # Scholarship search page
├── webinar.html                # Webinars overview page
├── beasiswa-lpdp.html          # Page detailing the LPDP scholarship
├── beasiswa-unggulan.html       # Page detailing the Unggulan scholarship
├── beasiswa-djarum.html         # Page detailing the Djarum scholarship
├── webinar-tips-lolos-beasiswa.html # Webinar on tips for winning scholarships
├── webinar-menulis-essay.html   # Workshop on writing scholarship essays
├── webinar-persiapan-ielts.html  # Webinar on IELTS preparation
```

Each HTML file corresponds to a specific section of the platform, allowing for easy navigation and access to resources.
